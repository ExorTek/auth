# `@exortek/auth`

A framework-agnostic authentication toolkit for Node.js — built as 20 small packages under one scope. Pick the one you
need, or install the umbrella.

Every package is built on `node:crypto` with zero required non-`@exortek/*` runtime dependencies. The heaviest primitives
(Argon2id, bcrypt) come from opt-in peer packages you install only if you use them. Pure JavaScript with JSDoc → `.d.ts`.
Ships adapters for Express and Fastify — the classic Node HTTP stack.

## The stack

Numbers reflect dependency order — a lower number never imports from a higher one, so you can adopt one package at a
time.

| #  | Package                              | What it does                                                                              |
|:--:|--------------------------------------|-------------------------------------------------------------------------------------------|
| 01 | [`@exortek/crypto`](/crypto)         | crypto primitives — the foundation the rest builds on                                     |
| 02 | [`@exortek/password`](/password)     | Argon2id / scrypt / bcrypt / PBKDF2, strength scoring, HIBP breach check, peppering       |
| 03 | [`@exortek/otp`](/otp)               | TOTP / HOTP, backup codes, QR provisioning URI                                            |
| 04 | [`@exortek/challenge`](/challenge)   | HMAC-signed multi-step flow tokens with opt-in single-use + IP binding                    |
| 05 | [`@exortek/jwk`](/jwk)               | generate / import / export JWK ↔ PEM (EC · RSA · OKP · oct), RFC 7638 + 9278 thumbprints  |
| 06 | [`@exortek/jws`](/jws)               | JWS compact + JSON, detached (§F), `b64:false`, HS / RS / PS / ES / EdDSA + secp256k1     |
| 07 | [`@exortek/jwt`](/jwt)               | JWT sign / verify / peek, tokenPair with RFC 6749 §10.4 reuse detection, blacklist stores |
| 08 | `@exortek/jwe`                       | JWE encrypted payloads (RSA-OAEP, A256KW, dir)                                            |
| 09 | [`@exortek/jwks`](/jwks)             | JWKS local key set + remote URI fetching, caching, zero-downtime `kid` rotation           |
| 10 | [`@exortek/session`](/session)       | sealed cookies, rotation, revocation, sudo mode, impersonation, Redis pub/sub             |
| 11 | [`@exortek/security`](/security)     | CSRF, rate-limit, helmet-style headers, CORS, safe-redirect + defensive HTTP helpers      |
| 12 | [`@exortek/ua`](/ua)                 | User-Agent parsing, device/browser/bot detection, Client Hints, fingerprinting            |
| 13 | [`@exortek/apikey`](/apikey)         | Stripe-style prefixed API keys with HMAC-hashed storage, scopes, and middleware           |
| 14 | [`@exortek/magic-link`](/magic-link) | passwordless email-link auth — HMAC-signed short-lived tokens with single-use consume     |
| 15 | [`@exortek/passkey`](/passkey)       | WebAuthn Level 3 / FIDO2 server — all seven attestation formats + MDS3 + AAGUID           |
| 16 | [`@exortek/opaque`](/opaque)          | opaque reference tokens — RFC 7662 introspection + RFC 7009 revocation                     |
| 17 | `@exortek/paseto`                    | PASETO v4 (`local` / `public`)                                                            |
| 18 | `@exortek/oauth2`                    | OAuth 2.1 client (PKCE) + provider presets                                                |
| 19 | `@exortek/oidc`                      | OpenID Connect on top of `oauth2`                                                         |
| 20 | `@exortek/auth`                      | umbrella — re-exports every package above                                                 |

## Install

Every published package installs on its own:

```bash
npm install @exortek/crypto
npm install @exortek/security
npm install @exortek/otp
npm install @exortek/password         # + optional: argon2, bcryptjs
npm install @exortek/session          # + optional: ioredis or redis
npm install @exortek/jwk
npm install @exortek/jws
npm install @exortek/jwt              # + optional: ioredis or redis
npm install @exortek/challenge        # + optional: ioredis or redis for single-use
npm install @exortek/apikey           # + optional: ioredis or redis, express or fastify
npm install @exortek/magic-link       # + optional: ioredis or redis
npm install @exortek/jwks
npm install @exortek/ua               # + optional: express or fastify
npm install @exortek/opaque           # + optional: ioredis or redis, express or fastify
npm install @exortek/passkey          # + optional: ioredis or redis, express or fastify
```

Node.js **22 or newer**.

  provisioning URIs, opt-in replay defense.
- **[`@exortek/password` reference →](/password)** — Argon2id, scrypt, bcrypt, PBKDF2 under one API +

- **[`@exortek/jwk` reference →](/jwk)** — generate / import / export EC · RSA · OKP · oct keys, RFC 7638 + 9278
  thumbprints, `toPublic()` / `matches()` / strict `use` × `key_ops` consistency.
- **[`@exortek/jws` reference →](/jws)** — JWS compact + JSON serialisation, detached content, unencoded payload,
  mandatory `alg` allowlist, `alg: 'none'` refused everywhere, granular `ErrorCode` enum.
- **[`@exortek/jwt` reference →](/jwt)** — RFC 7519 + 8725 + 9068 JWT with `sign` / `verify` / `peek`, `tokenPair`
  create / rotate / revoke with RFC 6749 §10.4 reuse detection, memory / Redis / custom stores, 26 error codes.
- **[`@exortek/challenge` reference →](/challenge)** — HMAC-signed multi-step flow tokens carrying
  `userId` / `method` / `step` / `nextStep` / `metadata`, opt-in single-use + IP binding, memory / Redis stores.
- **[`@exortek/apikey` reference →](/apikey)** — Stripe-style prefixed API keys with HMAC-SHA256 storage,

- **[`@exortek/magic-link` reference →](/magic-link)** — passwordless email-link auth — HMAC-signed short-lived

- **[`@exortek/jwks` reference →](/jwks)** — JWK Set (RFC 7517 §5) — local key set with zero-downtime rotation,

- **[`@exortek/ua` reference →](/ua)** — User-Agent parsing, device/browser/bot detection, Client Hints,
  fingerprinting, Express + Fastify middleware, bot-guard.
- **[`@exortek/opaque` reference →](/opaque)** — opaque reference tokens, RFC 7662 introspection + RFC 7009

- **[`@exortek/passkey` reference →](/passkey)** — WebAuthn Level 3 / FIDO2 server verification with all seven
