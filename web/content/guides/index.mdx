# Guides

The package references document every export in isolation. These guides do the
opposite: they wire packages together into **complete, copy-pasteable flows** —
the kind of thing you actually ship.

Each guide is framework-agnostic. The examples use Express-style
`req` / `res` handlers, but the `@exortek/*` calls are plain functions — drop
them into Fastify, a route handler, or a background job unchanged.

## Recipes

- **[Email + password login →](/guides/password-login)** — Argon2id hashing,
  constant-time verify with silent rehash, and sealed session cookies.
  Uses [`@exortek/password`](/password) + [`@exortek/session`](/session).
- **[JWT access + refresh →](/guides/jwt-access-refresh)** — short-lived access
  tokens, rotating refresh tokens, and RFC 6749 §10.4 reuse detection.
  Uses [`@exortek/jwt`](/jwt).
- **[Two-factor auth (TOTP) →](/guides/two-factor)** — enrol an authenticator
  app, verify 6-digit codes, and fall back to backup codes.
  Uses [`@exortek/otp`](/otp).
- **[Passwordless magic link →](/guides/magic-link)** — email a signed,
  single-use sign-in link and consume it on the way back.
  Uses [`@exortek/magic-link`](/magic-link).
- **[API key gateway →](/guides/api-keys)** — issue Stripe-style prefixed keys,
  store only their hash, and gate routes by scope.
  Uses [`@exortek/apikey`](/apikey).
