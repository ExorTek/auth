# `@exortek/ua`

High-performance User-Agent parser for Node.js 22+. Detects browsers,
operating systems, devices, engines, CPUs, and bots — with Client Hints
support, request fingerprinting, and middleware for Express and Fastify.
Zero dependencies. Pure `node:crypto`.

## What problem does this solve?

The UA-parsing space has a few established players and each leaves gaps:

- **`ua-parser-js`** — 10M downloads/week, good browser coverage, but no
  bot taxonomy, no Client Hints, no fingerprinting, no middleware, and the
  v2 paywall fragmented the community.
- **`bowser`** — clean API but abandoned since 2021, no new browsers or
  device types, no bot detection, no Client Hints.
- **`useragent`** — regex-file-based, slow to update, no structured bot
  classification, no modern device categories (XR, vehicles, IoT).
- **`isbot`** — bot detection only, no parsing. Good at what it does but
  you still need a second library for everything else.

`@exortek/ua` ships everything — parsing, bot taxonomy, Client Hints,
fingerprinting, and framework middleware — in one zero-dep package with
an LRU cache, keyword pre-filters, and lazy getters for performance.

## Quick start

```js
import { parse } from '@exortek/ua';

const result = parse(req.headers['user-agent']);

result.browser;  // { name: 'Chrome', version: '126.0.0.0', major: '126' }
result.os;       // { name: 'Windows', version: '10' }
result.device;   // { type: 'mobile', vendor: 'Apple', model: 'iPhone' }
result.engine;   // { name: 'Blink', version: '126.0.0.0' }
result.cpu;      // { architecture: 'amd64' }
```

## With middleware (recommended)

The middleware auto-negotiates Client Hints headers, detects bots, and
attaches the parsed result to every request.

```js
import express from 'express';
import { uaMiddleware } from '@exortek/ua/middleware/express';

const app = express();
app.use(uaMiddleware());

app.get('/', (req, res) => {
  const { browser, os, device, bot } = req.ua;
  res.json({ browser: browser.name, os: os.name, isBot: !!bot });
});
```

Or apply it to specific routes only:

```js
import express from 'express';
import { uaMiddleware } from '@exortek/ua/middleware/express';

const app = express();
const ua = uaMiddleware();

app.get('/analytics', ua, (req, res) => {
  res.json({
    browser: req.ua.browser.name,
    device: req.ua.device.type || 'desktop',
  });
});

app.get('/health', (req, res) => {
  res.json({ ok: true });
});
```

## Coverage

The parser ships with built-in regex sets covering:

- **60+ browsers** — Chrome, Firefox, Safari, Edge, Opera, Brave, Samsung Internet, UC Browser, Vivaldi, Arc, and many more (including in-app, email clients, media players)
- **30+ operating systems** — Windows, macOS, Linux, Android, iOS, ChromeOS, HarmonyOS, and more
- **8 device categories** — mobile, tablet, smarttv, console, xr, vehicle, wearable, embedded
- **100+ bot signatures** — search, AI training, AI assistant, social preview, SEO, monitoring, CLI, library
- **128 unit tests** covering parsing, bot detection, Client Hints, middleware hooks, and bot guard.

<Callout type="warning">
  User-Agent and Client Hints headers are **client-controlled** — they can
  be spoofed. Do not use parse results for authentication, authorization, or
  security decisions. They are useful for analytics, feature detection,
  content negotiation, and UX adaptation.
</Callout>
